Grammar in the Paninian tradition is not a disconnected catalogue of dry formulas;
it is a generative, logical algorithm where elemental roots (धातवः) are transformed
into boundless lexical expressions:
  1. Upasargas (उपसर्गाः - 22 Prefixes): Dynamic modifiers that forcefully alter,

     proximity rules (सह, अलम्, नमः, परितः, उभयतः, बहिः, उपरि, अधः).
  4. Sandhi Mechanics (स्वर एवं व्यञ्जन-सन्धिः): Phonological euphony rules (अयादि,
     पूर्वरूप, श्चुत्व, जश्त्व, अनुस्वार, परसवर्ण, णत्व-विधानम्) ensuring organic phonetic flow.

1. Upasargah (Prefixes / उपसर्गाः)
--------------------------------------------------------------------------------
[Sanskrit Theory]
धातोः पूर्वम् उपसर्गान् योजयित्वा नूतनक्रियापदानां निर्माणं क्रियते। सामान्यतः द्वाविंशतिः (२२) उपसर्गाः सन्ति।
तद्यथा — प्र, परा, अप, सम्, अनु, अव, निस्, निर्, दुस्, दुर्, वि, आङ् (आ), नि, अधि, अपि, अति, सु, उत्, अभि, प्रति, परि, उप।

[Hindi & English Translation]
धातुओं से पहले उपसर्गों को जोड़कर नए क्रियापदों (verbs) का निर्माण किया जाता है। संस्कृत में सामान्यतः २२ (द्वाविंशतिः) उपसर्ग होते हैं।
By adding prefixes before roots, new verbal forms are constructed. There are generally 22 prefixes in Sanskrit.

[Key Rules of Upasargas]:
1. Position (स्थानम्): They always appear directly before the verb root (धातोः पूर्वं भवन्ति).
2. Semantic Shift (अर्थ-परिवर्तनम्): Sometimes an Upasarga completely changes or reverses the meaning of the root.
   • Example: गच्छति (goes) → प्रति + आ + गच्छति = प्रत्यागच्छति (returns).
3. Enhancement (उत्कर्षः): Sometimes it merely amplifies or strengthens the existing meaning without reversing it.
   • Example: शोभते (looks beautiful) → सु + शोभते = सुशोभते (looks splendidly beautiful).
4. Multiple Upasargas (एकाधिकाः उपसर्गाः): A root can be preceded by two or more prefixes simultaneously.
   • Example: प्रति + आ + गच्छति = प्रत्यागच्छति; सम् + प्र + दा + ल्यप् = सम्प्रदाय.
5. Voice / Padam Conversion (पद-परिवर्तनम्): An Upasarga can change a Parasmaipadi root into Atmanepadi, or vice versa.
   • Examples: वि + जयति = विजयते (Parasmai → Atmane); वि + रमते = विरमति (Atmane → Parasmai).

[The Metaphorical Verse / धात्वर्थ-परिवर्तन-श्लोकः]:
उपसर्गेण धात्वर्थो बलादन्यत्र नीयते।
प्रहाराहारसंहारविहारपरिहारवत्॥

Meaning: The prefix forcefully shifts the core meaning of a root, just like the variations seen when adding prefixes to the root हृ (हारः):
• प्र + हृ = प्रहारः → आक्रमण / चोट (Assault / Blow / Strike)
• आ + हृ = आहारः → भोजन (Food / Diet / Nourishment)
• सम् + हृ = संहारः → विनाश / अंत (Destruction / Annihilation)
• वि + हृ = विहारः → घूमना-फिरना (Recreation / Wandering / Pleasure tour)
• परि + हृ = परिहारः → समाधान / त्याग (Remedy / Avoidance / Removal)


2. Pratyayah (Suffixes / प्रत्ययाः)
--------------------------------------------------------------------------------
[Sanskrit Theory]
धातोः प्रातिपदिकात् च अनन्तरं यः वर्ण-समुदायः वर्णः वा प्रयुज्यते सः प्रत्ययः भवति। धातुभ्यः संज्ञापदानि, विशेषणपदानि अव्ययपदानि वा निर्मातुं कृत्-प्रत्ययाः योज्यन्ते।

[Hindi & English Translation]
धातु या प्रातिपदिक (noun bases) के बाद जो वर्ण या वर्णों का समूह जोड़ा जाता है, उसे प्रत्यय कहते हैं। धातुओं से संज्ञा (nouns), विशेषण (adjectives), या अव्यय (indeclinables) बनाने के लिए कृत्-प्रत्ययों का प्रयोग किया जाता है।
A group of letters or a letter added after a root or a nominal stem is called a Pratyaya (suffix). Krit suffixes are appended to roots to generate nouns, adjectives, or indeclinables.

[Core Krit Pratyayas Covered]:
• क्त्वा (Ktvā): Used when the same subject performs two actions sequentially. It attaches to the former action to mean "after doing" or "having done" (करके / कर). The resulting word is an indeclinable (अव्ययम्).
  • Example: बालकः पठति + लिखति → बालकः पठित्वा लिखति (The boy writes after reading).
• ल्यप् (Lyap): Used in place of क्त्वा when the verbal root is preceded by an Upasarga (उपसर्गयुक्त-धातोः क्त्वा-स्थाने ल्यप् भवति). The resulting word is an indeclinable (अव्ययम्).
  • Example: सम् + पूज् + ल्यप् = सम्पूज्य (Having worshipped); वि + ज्ञा + ल्यप् = विज्ञाय (Having known).
• तुमुन् (Tumun): Used to express purpose or intention ("in order to", "for the purpose of" / के लिए) attached to the causative or intended action. Forms an indeclinable (अव्ययम्).
  • Example: रमेशः पठितुं विद्यालयं गच्छति (Ramesh goes to school in order to study).
• क्तवतु (Ktavatu): Used to form past active participles (भूतकालिक-कर्तृवाच्य). These forms decline like adjectives and agree with the subject in gender, number, and case:
  • Masculine (पुंलिङ्ग): हसितवान् (He laughed / भगवत्-वत् रूपम्)
  • Feminine (स्त्रीलिङ्ग): हसितवती (She laughed / नदी-वत् रूपम्)
  • Neuter (नपुंसकलिङ्ग): हसितवत् (जगत-वत् रूपम्)

A. Karak-Vibhakti (Case Endings based on Syntax / कारक-विभक्तिः)
--------------------------------------------------------------------------------
Defined by the direct semantic relationship to the verb: "क्रियान्वयि कारकम्।"
There are strictly 6 Karakas in Sanskrit grammar (Genitive / सम्बन्ध is not a Karaka
because it denotes an inter-noun possession, not a direct action relationship):

1. **कर्ता (Agent / Subject)**: Independent performer of the action (स्वतन्त्रः कर्ता).
   • Uses **प्रथमा विभक्तिः** (Nominative).
   • Example: रामः गच्छति। (Ram goes).
2. **कर्म (Direct Object)**: The most desired entity of the agent (कर्तुरीप्सिततमं कर्म).
   • Uses **द्वितीया विभक्तिः** (Accusative).
   • Example: रामः वनं गच्छति। (Ram goes to the forest).
3. **करण (Instrument)**: The absolute optimal means/tool of action (साधकतमं करणम्).
   • Uses **तृतीया विभक्तिः** (Instrumental).
   • Example: रामः पुष्पकविमानेन अयोध्यां गच्छति। (Ram goes by Pushpaka chariot).
4. **सम्प्रदानम् (Dative / Recipient)**: Whom the agent wishes to satisfy through a gift (कर्मणा यमभिप्रेति स सम्प्रदानम्).
   • Uses **चतुर्थी विभक्तिः** (Dative).
   • Example: गुरुः शिष्याय ज्ञानं ददाति। (The teacher gives knowledge to the disciple).
5. **अपादानम् (Ablative / Source of Separation)**: The stationary point from which separation occurs (ध्रुवमपायेऽपादानम्).
   • Uses **पञ्चमी विभक्तिः** (Ablative).
   • Example: वृक्षात् पत्रं पतति। (A leaf falls from the tree).
6. **अधिकरणम् (Locative / Base of Action)**: The spatial or temporal locus of the action (आधारोऽधिकरणम्).
   • Uses **सप्तमी विभक्तिः** (Locative).
   • Example: छात्राः विद्यालये पठन्ति। (Students study in the school).

• **सम्बन्ध-विभक्तिः (Genitive / Possessive)**: Non-karaka possessive relationship (षष्ठी विभक्तिः).
  • Example: रामस्य राजधानी अयोध्या आसीत्। (Ram's capital was Ayodhya).
• **सम्बोधन-विभक्तिः (Vocative)**: Form of प्रथमा used for addressing or calling out.
  • Example: हे राम! अत्र आगच्छ। (O Ram, come here!).

B. Sandhi Rules Breakdown (सन्धि-प्रकरणम्)
--------------------------------------------------------------------------------

1. Svara-Sandhi (Vowel Alterations)
• **Ayadi Sandhi (अयादि-सन्धिः)**:
  When diphthongs ए, ऐ, ओ, औ are followed by any vowel, they transform sequentially into अय्, आय्, अव्, आव्.
  - ए + स्वरः → अय्  ➔ शे + अनम् = शयनम्; ने + अनम् = नयनम्
  - ऐ + स्वरः → आय्  ➔ गै + अकः = गायकः; नै + अकः = नायकः
  - ओ + स्वरः → अव्  ➔ भो + अनम् = भवनम्; पो + अनः = पवनः
  - औ + स्वरः → आव्  ➔ नौ + इकः = नाविकः; पौ + अकः = पावकः
• **Purvarupa Sandhi (पूर्वरूप-सन्धिः)**:
  When word-ending (पदान्त) ए or ओ is followed by short अ, the अ blends completely into the previous vowel and is graphically replaced by an Avagraha ('ऽ').
  - पदान्तः ए + अ → एऽ ➔ ते + अपि = तेऽपि; वने + अत्र = वनेऽत्र
  - पदान्तः ओ + अ → ओऽ ➔ नमो + अस्तु = नमोऽस्तु; सो + अवदत् = सोऽवदत्

2. Vyanjana-Sandhi (Consonant Alterations)
• **Schutva Sandhi (श्चुत्व-सन्धिः — स्तोः श्चुना श्चुः)**:
  When dental स or त-वर्ग (त्, थ्, द्, ध्, न्) meets palatal श or च-वर्ग (च्, छ्, ज्, झ्, ञ्), the dentals convert directly into their corresponding palatals (स् → श्, त् → च्, etc.).
  - मनस् + चञ्चलम् = मनश्चञ्चलम्
  - उत् + चारणम् = उच्चारणम्
  - सत् + चित् = सच्चित्
  - हरिस् + शेते = हरिश्येते
• **Jashtva Sandhi (जश्त्व-सन्धिः — झलां जशोऽन्ते)**:
  When word-final non-nasal consonants (वर्ग-प्रथमाः क्, च्, ट्, त्, प्) encounter a vowel or a voiced consonant, they shift into the 3rd consonant (तृतीय-वर्णः: ग्, ज्, ड्, द्, ब्) of their respective varga.
  - वाक् + अर्थौ = वागार्थौ (क् → ग्)
  - जगत् + ईशः = जगदीशः (त् → द्)
  - अच् + अन्तः = अजन्तः (च् → ज्)
• **Anusvara Sandhi (अनुस्वार-सन्धिः — मोऽनुस्वारः)**:
  Word-final म् changes into an Anusvara dot (ं) when followed by any consonant.
  - रामम् + वन्दे = रामं वन्दे
  - धर्मम् + चर = धर्मं चर
• **Parasavarna Sandhi (परसवर्ण-सन्धिः — अनुस्वारस्य ययि परसवर्णः)**:
  When an Anusvara is followed by a varga consonant, it optionally or obligatorily changes into the 5th nasal letter (पञ्चम-वर्णः) of that following consonant's class.
  - अं + कितः = अङ्कितः (क-वर्ग पञ्चम = ङ्)
  - अं + चितः = अञ्चितः (च-वर्ग पञ्चम = ञ्)
• **Natva-Vidhanam (णत्व-विधानम् — रषाभ्यां नो णः समानपदे)**:
  When the dental nasal न falls after sounds ऋ, ॠ, र, or ष, it transforms into retroflex nasal ण, even if separated by vowels, gutturals (क-वर्ग), labials (प-वर्ग), or य, व, ह.
  - नरा + नाम् = नराणाम्
  - राम + अयनम् = रामायणम्

QUESTION BANK - 1 (Karakas & Upapada Applications / कारकाणि उपपद-विभक्तयश्च)
================================================================================

1. संस्कृतव्याकरणे कति कारकाणि भवन्ति?
   • उत्तरम्: षट् (६)
   • Rationale: "क्रियान्वयि कारकम्" — Sanskrit grammar recognizes strictly six Karakas (कर्ता, कर्म, करण, सम्प्रदान, अपादान, अधिकरण). Genitive (सम्बन्ध) is an inter-nominal relation, not an action governor.

2. कर्तृ-कारके का विभक्तिः प्रयुज्यते?
   • उत्तरम्: प्रथमा विभक्तिः (Nominative)
   • Rationale: The independent agent of the action takes the nominative case (स्वतन्त्रः कर्ता / प्रातिपदिकार्थलिङ्गपरिमाणवचनमात्रे प्रथमा).

3. 'सह' इति शब्दस्य योगे का विभक्तिः भवति?
   • उत्तरम्: तृतीया विभक्तिः (Instrumental)
   • Rationale: According to Panini's rule "सहयुक्तेऽप्रधाने", the companion/secondary participant takes the 3rd case (e.g., पुत्रेण सह).

4. 'नमः' इत्यस्य अव्ययस्य प्रयोगे का विभक्तिः विहिता?
   • उत्तरम्: चतुर्थी विभक्तिः (Dative)
   • Rationale: Panini sutra "नमःस्वस्तिस्वाहास्वधाऽलंवषड्योगाच्च" prescribes the dative case for obeisance (e.g., गुरवे नमः).

5. "वृक्षात् पत्रं पतति" — अत्र 'वृक्षात्' पदे का विभक्तिः किमर्थं च अस्ति?
   • उत्तरम्: पञ्चमी विभक्तिः, अपादानकारके (Ablative of separation)
   • Rationale: "ध्रुवमपायेऽपादानम्" — the stationary point of detachment takes the 5th case.

6. 'उभयतः' इति पदस्य योगे कस्याः विभक्तेः नियमः अस्ति?
   • उत्तरम्: द्वितीया विभक्तिः (Accusative)
   • Rationale: Words like उभयतः, परितः, सर्वतः, प्रति govern the accusative case (द्वितीया).

7. क्रियायाः आधारः कः कारकः मन्यते?
   • उत्तरम्: अधिकरणकारकः (सप्तमी विभक्तिः / Locative)
   • Rationale: "आधारोऽधिकरणम्" — the spatial or temporal locus of action is Adhikarana.

8. 'अलं' पदस्य निषेधार्थे कस्याः विभक्तेः प्रयोगः क्रियते?
   • उत्तरम्: तृतीया विभक्तिः (Instrumental of prohibition)
   • Rationale: In the sense of prevention or enough, 'Alam' requires the 3rd case (e.g., अलं विवादेन).

9. "पिता पुत्रेण सह आगच्छति" — अत्र कारकविभक्तिः अस्ति उत उपपदविभक्तिः?
   • उत्तरम्: उपपद-विभक्तिः
   • Rationale: The 3rd case on पुत्रेण is caused by the proximity of the specific indeclinable 'सह' (Upapada-vibhakti).

10. कस्य सम्बन्धस्य कारकाणां गणना न भवति?
    • उत्तरम्: सम्बन्धस्य (षष्ठी विभक्तेः / Genitive)
    • Rationale: Possessive relationships do not connect directly with the verb root, hence excluded from the six Karakas.

QUESTION BANK - 2 (Verbal Roots & Morphological Derivations / धातवः कृत्-प्रत्ययाश्च)
================================================================================

1. 'ल्यप्' प्रत्ययस्य प्रयोगः कदा भवति?
   • उत्तरम्: यदा धातुः उपसर्गेण युक्तः भवति (क्त्वा-स्थाने)
   • Rationale: "समासेऽनञ्पूर्वे क्त्वो ल्यप्" — when a root is compounded with a prefix (except negative 'अन्'), Lyap replaces Ktva.

2. 'गम्' धातोः 'तुमुन्' प्रत्यये किं रूपं निष्पद्यते?
   • उत्तरम्: गन्तुम् (In order to go)
   • Rationale: गम + तुमुन् = गन्तुम् (makara shifts to dental nakara before dental takara).

3. 'ज्ञा' धातोः 'ल्यप्' प्रत्यये किं रूपं जायते?
   • उत्तरम्: विज्ञाय (Having known / understood)
   • Rationale: वि + ज्ञा + ल्यप् = विज्ञाय (ya remains, lakara and pakara are elided).

4. 'श्रु' धातोः स्त्रीलिङ्गे 'क्तवतु' प्रत्ययस्य रूपं किं भविष्यति?
   • उत्तरम्: श्रुतवती (She heard / listened)
   • Rationale: श्रु + क्तवतु feminine stem is श्रुतवती (declined like 'नदी').

5. 'त्यजति' इति क्रियापदस्य 'क्त्वा' प्रत्यये परिवर्तनं कुरुत।
   • उत्तरम्: त्यक्त्वा (Having abandoned)
   • Rationale: त्यज् + क्त्वा = त्यक्त्वा (j reflects into k before t).

6. 'ददाति' धातोः 'तुमुन्' प्रत्ययान्तरूपं किम्?
   • उत्तरम्: दातुम् (In order to give)
   • Rationale: दा + तुमुन् = दातुम्.

7. 'प्रक्षाल्य' पदे कः उपसर्गः, कः धातुः, कश्च प्रत्ययः अस्ति?
   • उत्तरम्: प्र (उपसर्गः) + क्षाल् (धातुः) + ल्यप् (प्रत्ययः)
   • Rationale: Preceded by prefix 'pra', root 'kshal' takes the suffix 'lyap'.

8. 'पठितवान्' पदस्य कः प्रत्ययः अस्ति?
   • उत्तरम्: क्तवतु प्रत्ययः (Past active participle)
   • Rationale: पठ् + क्तवतु (masculine singular nominative) = पठितवान्.

9. 'गृहीत्वा' पदे मूलधातुः कः अस्ति?
   • उत्तरम्: ग्रह् धातुः (To seize / catch)
   • Rationale: ग्रह् + क्त्वा = गृहीत्वा (root vowel Samprasarana).

10. 'उदित्वा' पदे कस्य धातुमूलात् परिवर्तनं जातम्?
    • उत्तरम्: वद् धातुः (To speak)
    • Rationale: वद् + क्त्वा = उदित्वा (semivowel v undergoes Samprasarana to vowel u).

QUESTION BANK - 3 (Sandhi Alterations & Form Identification / सन्धि-नियमाः रूपाणि च)
================================================================================

1. 'भवनम्' इति पदस्य कः सन्धिच्छेदः अस्ति?
   • उत्तरम्: भो + अनम् (अयादि-सन्धिः)
   • Rationale: Diphthong 'o' followed by vowel 'a' transforms into 'av' (भो ➔ भव् + अनम् = भवनम्).

2. 'तेऽपि' पदे कः सन्धिः प्रयुक्तः?
   • उत्तरम्: पूर्वरूप-सन्धिः (एङ्ः पदान्तादति)
   • Rationale: Word-final 'e' absorbs following short 'a', marked by the Avagraha glyph 'ऽ'.

3. 'वाक् + अर्थौ' इत्यस्य सन्धिपदं किं भविष्यति?
   • उत्तरम्: वागार्थौ (जश्त्व-सन्धिः)
   • Rationale: Class-first stop 'k' followed by vowel converts to 3rd stop 'g' (वाक् + अर्थौ = वागार्थौ).

4. 'उत् + चारणम्' अत्र कस्य सन्धि नियमः अस्ति?
   • उत्तरम्: श्चुत्व-सन्धिः (उच्चारणम् — स्तोः श्चुना श्चुः)
   • Rationale: Dental stop 't' assimilates to palatal stop 'c' when meeting a palatal (उत् + चारणम् = उच्चारणम्).

5. 'अं + कितः' इत्यस्य परसवर्णसन्धि रूपं लिखत।
   • उत्तरम्: अङ्कितः
   • Rationale: Anusvara before guttural 'k' assimilates to guttural nasal 'ṅ' (अङ्कितः).

6. 'रामायणम्' इत्यत्र 'न'कारस्य 'ण'कारः केन विधानेन भवति?
   • उत्तरम्: णत्व-विधानेन (रषाभ्यां नो णः समानपदे)
   • Rationale: Intervening vowels and labial 'm' do not block 'r' from retroflexing following 'n' into 'ṇ'.

7. 'नमोऽस्तु' इत्यस्य सन्धिं विच्छेद्य नियमं वदत।
   • उत्तरम्: नमो + अस्तु (पूर्वरूप-सन्धिः)
   • Rationale: Word-final 'o' absorbs following short 'a' into Purvarupa with Avagraha.

8. 'गायकः' पदे कः स्वरसन्धिभेदः अस्ति?
   • उत्तरम्: अयादि-सन्धिः (गै + अकः — ऐ ➔ आय्)
   • Rationale: Diphthong 'ai' followed by vowel changes to 'āy' (गै + अकः = गायकः).

9. 'हरिस् + शेते' इत्यस्य श्चुत्वसन्धि रूपं किम्?
   • उत्तरम्: हरिश्येते
   • Rationale: Dental sibilant 's' converts into palatal sibilant 'ś' before 'ś'.

10. 'धर्मं चर' इत्यत्र मकारस्य अनुस्वारः कस्मात् कारणात् अभवत्?
    • उत्तरम्: अनुस्वारसन्धि नियमात् (मोऽनुस्वारः), उत्तरपदे व्यञ्जनस्य स्थितेः।
    • Rationale: Word-final 'm' converts into Anusvara when followed by any consonant (धर्मम् + चर = धर्मं चर).
