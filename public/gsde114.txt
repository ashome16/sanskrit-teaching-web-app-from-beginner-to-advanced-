Chapter 14 : परिशिष्टम् १ — शब्दरूपाणि (Declensions)

(अध्याय १४ : परिशिष्ट १ — शब्दरूपाणि / Declensions)

१. पूर्णः पाठः : अजन्ताः शब्दरूपाणि (Full Text - Vowel-Ending Noun & Pronoun Declensions)

अजन्ताः (अच् = स्वराः) स्वरवर्णाः अन्ते येषां ते अजन्ताः। (Words ending with a vowel sound are called Ajanta words).

(अर्थ: जिनके अंत में स्वर वर्ण (अच्) होते हैं, उन्हें 'अजन्त' शब्द कहते हैं। संस्कृत व्याकरण में शब्दरूपों को समझने के लिए अजन्त और हलन्त का ज्ञान आवश्यक है।)

१. पुंलिङ्गशब्दाः (Masculine Nouns)

‘अ’कारान्ताः पुंलिङ्गशब्दाः : ( देव = द् + ए + व + अ ) अत्र अन्तिमवर्णः ‘अ’ अतः ‘अ’कारान्तः इति ।

(अर्थ: अकारान्त पुल्लिंग शब्द: देव = द् + ए + व + अ, यहाँ अंतिम वर्ण 'अ' है, इसलिए इसे 'अकारान्त' कहते हैं।)

‘देव’ शब्दः (अकारान्तः पुंलिङ्गः - देव / God):

प्रथमा विभक्तिः (Nominative): देवः (एकवचनम्) देवौ (द्विवचनम्) देवाः (बहुवचनम्)

(अर्थ: प्रथमा विभक्ति - देव ने / एक देव, दो देव, सब देव)

द्वितीया विभक्तिः (Accusative): देवम् (एकवचनम्) देवौ (द्विवचनम्) देवान् (बहुवचनम्)

(अर्थ: द्वितीया विभक्ति - देव को / एक देव को, दो देवों को, सब देवों को)

तृतीया विभक्तिः (Instrumental): देवेन (एकवचनम्) देवाभ्याम् (द्विवचनम्) देवैः (बहुवचनम्)

(अर्थ: तृतीया विभक्ति - देव से, देव के द्वारा / एक देव से, दो देवों से, सब देवों से)

चतुर्थी विभक्तिः (Dative): देवाय (एकवचनम्) देवाभ्याम् (द्विवचनम्) देवेभ्यः (बहुवचनम्)

(अर्थ: चतुर्थी विभक्ति - देव के लिए / एक देव के लिए, दो देवों के लिए, सब देवों के लिए)

पञ्चमी विभक्तिः (Ablative): देवात् (एकवचनम्) देवाभ्याम् (द्विवचनम्) देवेभ्यः (बहुवचनम्)

(अर्थ: पञ्चमी विभक्ति - देव से (अलग होना) / एक देव से, दो देवों से, सब देवों से)

षष्ठी विभक्तिः (Genitive): देवस्य (एकवचनम्) देवयोः (द्विवचनम्) देवानाम् (बहुवचनम्)

(अर्थ: षष्ठी विभक्ति - देव का / के / की / एक देव का, दो देवों का, सब देवों का)

सप्तमी विभक्तिः (Locative): देवे (एकवचनम्) देवयोः (द्विवचनम्) देवेषु (बहुवचनम्)

(अर्थ: सप्तमी विभक्ति - देव में / पर / एक देव में, दो देवों में, सब देवों में)

सम्बोधनम् (Vocative): हे देव ! (एकवचनम्) हे देवौ ! (द्विवचनम्) हे देवाः ! (बहुवचनम्)

(अर्थ: सम्बोधन - हे देव! / हे एक देव!, हे दो देवो!, हे सब देवो!)

‘राम’ शब्दः (अकारान्तः पुंलिङ्गः - राम / Lord Rama):

प्रथमा विभक्तिः: रामः (एकवचनम्) रामौ (द्विवचनम्) रामाः (बहुवचनम्)

(अर्थ: प्रथमा विभक्ति - राम ने / एक राम, दो राम, सब राम)

द्वितीया विभक्तिः: रामम् (एकवचनम्) रामौ (द्विवचनम्) रामान् (बहुवचनम्)

(अर्थ: द्वितीया विभक्ति - राम को / एक राम को, दो रामों को, सब रामों को)

तृतीया विभक्तिः: रामेण (एकवचनम्) रामाभ्याम् (द्विवचनम्) रामैः (बहुवचनम्)

(अर्थ: तृतीया विभक्ति - राम से, राम के द्वारा / एक राम से, दो रामों से, सब रामों से)

चतुर्थी विभक्तिः: रामाय (एकवचनम्) रामाभ्याम् (द्विवचनम्) रामेभ्यः (बहुवचनम्)

(अर्थ: चतुर्थी विभक्ति - राम के लिए / एक राम के लिए, दो रामों के लिए, सब रामों के लिए)

पञ्चमी विभक्तिः: रामात् (एकवचनम्) रामाभ्याम् (द्विवचनम्) रामेभ्यः (बहुवचनम्)

(अर्थ: पञ्चमी विभक्ति - राम से (अलग होना) / एक राम से, दो रामों से, सब रामों से)

षष्ठी विभक्तिः: रामस्य (एकवचनम्) रामयोः (द्विवचनम्) रामाणाम् (बहुवचनम्)

सप्तमी विभक्तिः: रामे (एकवचनम्) रामयोः (द्विवचनम्) रामेषु (बहुवचनम्)

(अर्थ: सप्तमी विभक्ति - राम में / पर / एक राम में, दो रामों में, सब रामों में)

सम्बोधनम्: हे राम ! (एकवचनम्) हे रामौ ! (द्विवचनम्) हे रामाः ! (बहुवचनम्)

(अर्थ: सम्बोधन - हे राम! / हे एक राम!, हे दो रामो!, हे सब रामो!)

एवम् (Similarly): बाल, भीम, शिव, कृष्ण, हस्त, पाद, हर, कर, शर, शिक्षकः, वक्ष, चषक इत्यादयः।

(अर्थ: इसी प्रकार अन्य अकारान्त पुल्लिंग शब्दों के रूप चलते हैं, जैसे— बालक, भीम, शिव, कृष्ण, हस्त (हाथ), पाद (पैर), हर, कर (हाथ), शर (बाण), शिक्षक, वक्ष (छाती), चषक (प्याला) आदि।)

(अर्थ: प्रथमा विभक्ति - गुरु ने / एक गुरु, दो गुरु, सब गुरु)

द्वितीया विभक्तिः: गुरुम् (एकवचनम्) गुरू (द्विवचनम्) गुरून (बहुवचनम्)

(अर्थ: द्वितीया विभक्ति - गुरु को / एक गुरु को, दो गुरुओं को, सब गुरुओं को)

तृतीया विभक्तिः: गुरुणा (एकवचनम्) गुरुभ्याम् (द्विवचनम्) गुरुभिः (बहुवचनम्)

(अर्थ: तृतीया विभक्ति - गुरु से, गुरु के द्वारा / एक गुरु से, दो गुरुओं से, सब गुरुओं से)

चतुर्थी विभक्तिः: गुरवे (एकवचनम्) गुरुभ्याम् (द्विवचनम्) गुरुभ्यः (बहुवचनम्)

(अर्थ: चतुर्थी विभक्ति - गुरु के लिए / एक गुरु के लिए, दो गुरुओं के लिए, सब गुरुओं के लिए)

पञ्चमी विभक्तिः: गुरोः (एकवचनम्) गुरुभ्याम् (द्विवचनम्) गुरुभ्यः (बहुवचनम्)

(अर्थ: पञ्चमी विभक्ति - गुरु से (अलग होना) / एक गुरु से, दो गुरुओं से, सब गुरुओं से)

षष्ठी विभक्तिः: गुरोः (एकवचनम्) गुर्वोः (द्विवचनम्) गुरूणाम् (बहुवचनम्)

(अर्थ: षष्ठी विभक्ति - गुरु का / के / की / एक गुरु का, दो गुरुओं का, सब गुरुओं का)

सप्तमी विभक्तिः: गुरौ (एकवचनम्) गुर्वोः (द्विवचनम्) गुरुषु (बहुवचनम्)

(अर्थ: सप्तमी विभक्ति - गुरु में / पर / एक गुरु में, दो गुरुओं में, सब गुरुओं में)

सम्बोधनम्: हे गुरो ! (एकवचनम्) हे गुरू ! (द्विवचनम्) हे गुरवः ! (बहुवचनम्)

(अर्थ: सम्बोधन - हे गुरो! / हे एक गुरु!, हे दो गुरुओ!, हे सब गुरुओ!)

एवम् (Similarly): मनु, वायु, पशु, ऋतु, शिशु, भानु, विष्णु, तरु, रिपु, प्रभु, इक्षु, शत्रु इत्यादयः।

(अर्थ: इसी प्रकार मनु, वायु (हवा), पशु (जानवर), ऋतु (मौसम), शिशु (बालक), भानु (सूर्य), विष्णु, तरु (वृक्ष), रिपु (शत्रु), प्रभु (स्वामी), इक्षु (गन्ना), शत्रु आदि उकारान्त पुल्लिंग शब्दों के रूप चलते हैं।)

‘ॠ’कारान्ताः पुंलिङ्गशब्दाः : ( पितृ = प + इ + त् + ॠ ) अत्र अन्तिमवर्णः ‘ॠ’ अतः ‘ॠ’कारान्तः इति ।

(अर्थ: ऋकारान्त पुल्लिंग शब्द: पितृ = प + इ + त् + ॠ, यहाँ अंतिम वर्ण 'ॠ' है, इसलिए इसे 'ॠकारान्त' कहते हैं।)

‘पितृ’ शब्दः (ऋकारान्तः पुंलिङ्गः - पिता / Father):

(अर्थ: द्वितीया विभक्ति - पिता को / एक पिता को, दो पिताओं को, सब पिताओं को)

चतुर्थी विभक्तिः: पित्रे (एकवचनम्) पितृभ्याम् (द्विवचनम्) पितृभ्यः (बहुवचनम्)

(अर्थ: चतुर्थी विभक्ति - पिता के लिए / एक पिता के लिए, दो पिताओं के लिए, सब पिताओं के लिए)

पञ्चमी विभक्तिः: पितुः (एकवचनम्) पितृभ्याम् (द्विवचनम्) पितृभ्यः (बहुवचनम्)

(अर्थ: पञ्चमी विभक्ति - पिता से (अलग होना) / एक पिता से, दो पिताओं से, सब पिताओं से)

षष्ठी विभक्तिः: पितुः (एकवचनम्) पित्रोः (द्विवचनम्) पितॄणाम् (बहुवचनम्)

(अर्थ: षष्ठी विभक्ति - पिता का / के / की / एक पिता का, दो पिताओं का, सब पिताओं का)

सप्तमी विभक्तिः: पितरि (एकवचनम्) पित्रोः (द्विवचनम्) पितृषु (बहुवचनम्)

(अर्थ: सप्तमी विभक्ति - पिता में / पर / एक पिता में, दो पिताओं में, सब पिताओं में)

सम्बोधनम्: हे पितः ! (एकवचनम्) हे पितरौ ! (द्विवचनम्) हे पितरः ! (बहुवचनम्)

(अर्थ: सम्बोधन - हे पिता! / हे एक पिता!, हे दो पिताओ!, हे सब पिताओ!)

‘नेतृ’ शब्दः (ऋकारान्तः पुंलिङ्गः - नेता / Leader):

प्रथमा विभक्तिः: नेता (एकवचनम्) नेतारौ (द्विवचनम्) नेतारः (बहुवचनम्)

(अर्थ: प्रथमा विभक्ति - नेता ने / एक नेता, दो नेता, सब नेता)

(अर्थ: द्वितीया विभक्ति - नेता को / एक नेता को, दो नेताओं को, सब नेताओं को)

(अर्थ: तृतीया विभक्ति - नेता से, नेता के द्वारा / एक नेता से, दो नेताओं से, सब नेताओं से)

चतुर्थी विभक्तिः: नेत्रे (एकवचनम्) नेतृभ्याम् (द्विवचनम्) नेतृभ्यः (बहुवचनम्)

(अर्थ: चतुर्थी विभक्ति - नेता के लिए / एक नेता के लिए, दो नेताओं के लिए, सब नेताओं के लिए)

पञ्चमी विभक्तिः: नेतुः (एकवचनम्) नेतृभ्याम् (द्विवचनम्) नेतृभ्यः (बहुवचनम्)

षष्ठी विभक्तिः: नेतुः (एकवचनम्) नेत्रोः (द्विवचनम्) नेतॄणाम् (बहुवचनम्)

(अर्थ: षष्ठी विभक्ति - नेता का / के / की / एक नेता का, दो नेताओं का, सब नेताओं का)

सप्तमी विभक्तिः: नेतरी (एकवचनम्) नेत्रोः (द्विवचनम्) नेतृषु (बहुवचनम्)

(अर्थ: सप्तमी विभक्ति - नेता में / पर / एक नेता में, दो नेताओं में, सब नेताओं में)

(अर्थ: सम्बोधन - हे नेता! / हे एक नेता!, हे दो नेताओ!, हे सब नेताओ!)

एवम् (Similarly): भ्रातृ, जामातृ, कर्तृ, धातृ, नप्तृ इत्यादयः।

(अर्थ: इसी प्रकार भ्रातृ (भाई), जामातृ (दामाद), कर्तृ (कर्ता), धातृ (विधाता), नप्तृ (पोता) आदि ऋकारान्त पुल्लिंग शब्दों के रूप चलते हैं।)

२. स्त्रीलिङ्गशब्दाः (Feminine Nouns)

‘आ’कारान्ताः स्त्रीलिङ्गशब्दाः : ( माला = म + आ + ल + आ ) अत्र अन्तिमवर्णः ‘आ’ अतः ‘आ’कारान्तः इति ।

(अर्थ: आकारान्त स्त्रीलिंग शब्द: माला = म + आ + ल + आ, यहाँ अंतिम वर्ण 'आ' है, इसलिए इसे 'आकारान्त' कहते हैं।)

‘माला’ शब्दः (आकारान्तः स्त्रीलिङ्गः - माला / Garland):

प्रथमा विभक्तिः: माला (एकवचनम्) माले (द्विवचनम्) मालाः (बहुवचनम्)

(अर्थ: प्रथमा विभक्ति - माला ने / एक माला, दो मालाएँ, सब मालाएँ)

द्वितीया विभक्तिः: मालाम् (एकवचनम्) माले (द्विवचनम्) मालाः (बहुवचनम्)

(अर्थ: द्वितीया विभक्ति - माला को / एक माला को, दो मालाओं को, सब मालाओं को)

तृतीया विभक्तिः: मालया (एकवचनम्) मालाभ्याम् (द्विवचनम्) मालाभिः (बहुवचनम्)

(अर्थ: तृतीया विभक्ति - माला से, माला के द्वारा / एक माला से, दो मालाओं से, सब मालाओं से)

चतुर्थी विभक्तिः: मालायै (एकवचनम्) मालाभ्याम् (द्विवचनम्) मालाभ्यः (बहुवचनम्)

(अर्थ: चतुर्थी विभक्ति - माला के लिए / एक माला के लिए, दो मालाओं के लिए, सब मालाओं के लिए)

पञ्चमी विभक्तिः: मालायाः (एकवचनम्) मालाभ्याम् (द्विवचनम्) मालाभ्यः (बहुवचनम्)

(अर्थ: पञ्चमी विभक्ति - माला से (अलग होना) / एक माला से, दो मालाओं से, सब मालाओं से)

षष्ठी विभक्तिः: मालायाः (एकवचनम्) मालयोः (द्विवचनम्) मालानाम् (बहुवचनम्)

(अर्थ: षष्ठी विभक्ति - माला का / के / की / एक माला का, दो मालाओं का, सब मालाओं का)

सप्तमी विभक्तिः: मालायाम् (एकवचनम्) मालयोः (द्विवचनम्) मालासु (बहुवचनम्)

(अर्थ: सप्तमी विभक्ति - माला में / पर / एक माला में, दो मालाओं में, सब मालाओं में)

सम्बोधनम्: हे माले ! (एकवचनम्) हे माले ! (द्विवचनम्) हे मालाः ! (बहुवचनम्)

(अर्थ: सम्बोधन - हे माले! / हे एक माला!, हे दो मालाओ!, हे सब मालाओ!)

एवम् (Similarly): सीता, सुधा, लता, गीता, राधा, विद्या, क्षमा, कक्षा, रेखा, रक्षा, शिक्षा इत्यादयः।

(अर्थ: इसी प्रकार सीता, सुधा (अमृत), लता (बेल), गीता, राधा, विद्या (ज्ञान), क्षमा, कक्षा (कक्षा/वर्ग), रेखा (लकीर), रक्षा, शिक्षा आदि आकारान्त स्त्रीलिंग शब्दों के रूप चलते हैं।)

३. नपुंसकलिङ्गशब्दाः (Neuter Nouns)

‘अ’कारान्ताः नपुंसकलिङ्गशब्दाः : ( फल = फ् + अ + ल + अ ) अत्र अन्तिमवर्णः ‘अ’ अतः ‘अ’कारान्तः नपुंसकलिङ्गः इति ।

(अर्थ: अकारान्त नपुंसकलिंग शब्द: फल = फ् + अ + ल + अ, यहाँ अंतिम वर्ण 'अ' है, इसलिए इसे 'अकारान्त नपुंसकलिंग' कहते हैं।)

‘फल’ शब्दः (अकारान्तः नपुंसकलिङ्गः - फल / Fruit):

प्रथमा विभक्तिः: फलम् (एकवचनम्) फले (द्विवचनम्) फलानि (बहुवचनम्)

(अर्थ: प्रथमा विभक्ति - फल ने / एक फल, दो फल, सब फल)

द्वितीया विभक्तिः: फलम् (एकवचनम्) फले (द्विवचनम्) फलानि (बहुवचनम्)

(अर्थ: द्वितीया विभक्ति - फल को / एक फल को, दो फलों को, सब फलों को)

तृतीया विभक्तिः: फलेन (एकवचनम्) फलाभ्याम् (द्विवचनम्) फलैः (बहुवचनम्)

(अर्थ: तृतीया विभक्ति - फल से, फल के द्वारा / एक फल से, दो फलों से, सब फलों से)

चतुर्थी विभक्तिः: फलाय (एकवचनम्) फलाभ्याम् (द्विवचनम्) फलेभ्यः (बहुवचनम्)

(अर्थ: चतुर्थी विभक्ति - फल के लिए / एक फल के लिए, दो फलों के लिए, सब फलों के लिए)

पञ्चमी विभक्तिः: फलात् (एकवचनम्) फलाभ्याम् (द्विवचनम्) फलेभ्यः (बहुवचनम्)

(अर्थ: पञ्चमी विभक्ति - फल से (अलग होना) / एक फल से, दो फलों से, सब फलों से)

षष्ठी विभक्तिः: फलस्य (एकवचनम्) फलयोः (द्विवचनम्) फलानाम् (बहुवचनम्)

(अर्थ: षष्ठी विभक्ति - फल का / के / की / एक फल का, दो फलों का, सब फलों का)

सप्तमी विभक्तिः: फले (एकवचनम्) फलयोः (द्विवचनम्) फलेषु (बहुवचनम्)

(अर्थ: सप्तमी विभक्ति - फल में / पर / एक फल में, दो फलों में, सब फलों में)

सम्बोधनम्: हे फल ! (एकवचनम्) हे फले ! (द्विवचनम्) हे फलानि ! (बहुवचनम्)

(अर्थ: सम्बोधन - हे फल! / हे एक फल!, हे दो फलो!, हे सब फलो!)

एवम् (Similarly): वन, धन, ज्ञान, नयन, पुस्तक, उद्यान, चक्र, चित्र, पत्र, मन्दिर, नेत्र, वस्त्र, पुष्प, गृह, नगर, द्वार इत्यादयः।

(अर्थ: इसी प्रकार वन (जंगल), धन, ज्ञान, नयन (नेत्र), पुस्तक (किताब), उद्यान (बगीचा), चक्र (पहिया), चित्र, पत्र (पत्ता/पत्र), मन्दिर, नेत्र (आँख), वस्त्र (वस्त्र/कपड़ा), पुष्प (फूल), गृह (घर), नगर (शहर), द्वार (दरवाजा) आदि अकारान्त नपुंसकलिंग शब्दों के रूप चलते हैं।)

४. सर्वनामशब्दाः (Pronouns)

‘अस्मद्’ (मैं / I) एवं ‘युष्मद्’ (तुम / You)

(अर्थ: सर्वनाम शब्द: 'अस्मद्' (मैं/हम) तथा 'युष्मद्' (तुम/आप), ये तीनों लिंगों (पुल्लिंग, स्त्रीलिंग, नपुंसकलिंग) में समान रूप से प्रयुक्त होते हैं।)

‘अस्मद्’ शब्दः (उत्तम-पुरुष-सर्वनाम - त्रिषु लिङ्गेषु समानम्):

प्रथमा विभक्तिः: अहम् (एकवचनम्) आवाम् (द्विवचनम्) वयम् (बहुवचनम्)

(अर्थ: प्रथमा विभक्ति - मैं ने / मैं, हम दोनों, हम सब)

द्वितीया विभक्तिः: माम् (एकवचनम्) आवाम् (द्विवचनम्) अस्मान् (बहुवचनम्)

(अर्थ: द्वितीया विभक्ति - मुझ को / मुझे, हम दोनों को, हम सबको)

तृतीया विभक्तिः: मया (एकवचनम्) आवाभ्याम् (द्विवचनम्) अस्माभिः (बहुवचनम्)

(अर्थ: तृतीया विभक्ति - मेरे द्वारा / मुझसे, हम दोनों से, हम सबसे)

चतुर्थी विभक्तिः: मह्यम् (एकवचनम्) आवाभ्याम् (द्विवचनम्) अस्मभ्यम् (बहुवचनम्)

(अर्थ: चतुर्थी विभक्ति - मेरे लिए / मुझे, हम दोनों के लिए, हम सबके लिए)

पञ्चमी विभक्तिः: मत् (एकवचनम्) आवाभ्याम् (द्विवचनम्) अस्मत् (बहुवचनम्)

(अर्थ: पञ्चमी विभक्ति - मुझसे (अलग होना) / मुझसे, हम दोनों से, हम सबसे)

षष्ठी विभक्तिः: मम (एकवचनम्) आवयोः (द्विवचनम्) अस्माकम् (बहुवचनम्)

(अर्थ: षष्ठी विभक्ति - मेरा / मेरी / मेरे / मेरा, हम दोनों का, हमारा/हम सबका)

सप्तमी विभक्तिः: मयि (एकवचनम्) आवयोः (द्विवचनम्) अस्मासु (बहुवचनम्)

(अर्थ: सप्तमी विभक्ति - मुझ में / मुझ पर / मुझ में, हम दोनों में, हम सब में)

‘युष्मद्’ शब्दः (मध्यम-पुरुष-सर्वनाम - त्रिषु लिङ्गेषु समानम्):

प्रथमा विभक्तिः: त्वम् (एकवचनम्) युवाम् (द्विवचनम्) यूयम् (बहुवचनम्)

(अर्थ: प्रथमा विभक्ति - तुम ने / तू/तुम, तुम दोनों, तुम सब)

द्वितीया विभक्तिः: त्वाम् (एकवचनम्) युवाम् (द्विवचनम्) युष्मान् (बहुवचनम्)

(अर्थ: द्वितीया विभक्ति - तुझ को / तुम्हें, तुम दोनों को, तुम सबको)

तृतीया विभक्तिः: त्वया (एकवचनम्) युवाभ्याम् (द्विवचनम्) युष्माभिः (बहुवचनम्)

(अर्थ: तृतीया विभक्ति - तेरे द्वारा / तुझसे, तुम दोनों से, तुम सबसे)

चतुर्थी विभक्तिः: तुभ्यम् (एकवचनम्) युवाभ्याम् (द्विवचनम्) युष्मभ्यम् (बहुवचनम्)

(अर्थ: चतुर्थी विभक्ति - तेरे लिए / तुम्हें, तुम दोनों के लिए, तुम सबके लिए)

पञ्चमी विभक्तिः: त्वत् (एकवचनम्) युवाभ्याम् (द्विवचनम्) युष्मत् (बहुवचनम्)

(अर्थ: पञ्चमी विभक्ति - तुझसे (अलग होना) / तुझसे, तुम दोनों से, तुम सबसे)

षष्ठी विभक्तिः: तव (एकवचनम्) युवयोः (द्विवचनम्) युष्माकम् (बहुवचनम्)

(अर्थ: षष्ठी विभक्ति - तेरा / तेरी / तेरे / तेरा, तुम दोनों का, तुम्हारा/तुम सबका)

सप्तमी विभक्तिः: त्वयि (एकवचनम्) युवयोः (द्विवचनम्) युष्मासु (बहुवचनम्)

(अर्थ: सप्तमी विभक्ति - तुझ में / तुझ पर / तुझ में, तुम दोनों में, तुम सब में)

२. शब्दार्थ-विवरणम् (विभक्ति-कारक-चिह्नानां विवरणम्)

Because this grammar section consists of paradigm templates (शब्दरूपाणि), the "word meanings" are based on how the case endings (विभक्तियाँ) change the core noun meaning:

(अर्थ: क्योंकि यह व्याकरण खंड शब्दरूपों (रूपावलियों) पर आधारित है, शब्द के अर्थ विभक्तियों के अनुसार कारक चिह्नों के साथ परिवर्तित होते हैं:)

विभक्तिः (Case) : कारक चिह्नानि (Hindi Meaning Marker) : English Function Equivalent

(१) प्रथमा (Nominative): ने (कर्ता - Subj.) — The subject (e.g., रामः = Ram / राम ने)

(२) द्वितीया (Accusative): को (कर्म - Obj.) — Direct object (e.g., रामम् = to Ram / राम को)

(३) तृतीया (Instrumental): से / के द्वारा (करण - Inst.) — By / With (e.g., रामेण = by Ram / राम के द्वारा)

(४) चतुर्थी (Dative): के लिए (सम्प्रदान - Dat.) — For / To (e.g., रामाय = for Ram / राम के लिए)

(५) पञ्चमी (Ablative): से (अपादान - अलग होने का भाव) — From (e.g., रामात् = from Ram / राम से)

(६) षष्ठी (Genitive): का / के / की (सम्बन्ध - Rel.) — Of / 's (e.g., रामस्य = Ram's / of Ram / राम का)

(७) सप्तमी (Locative): में / पर (अधिकरण - Loc.) — In / On (e.g., रामे = in Ram / on Ram / राम में)

(८) सम्बोधनम् (Vocative): हे! / अरे! (सम्बोधन - Voc.) — Calling out (e.g., हे राम ! = O Ram! / हे राम!)

३. अभ्यास-उत्तराणि (अभ्यास-प्रश्नानां समाधानानि)

The structured exercises ask you to complete tables or change single sentences using these specific words:

(अर्थ: पाठ्यपुस्तक के अभ्यास प्रश्नों में शब्दरूपों की तालिकाओं को पूर्ण करने और रिक्त स्थानों को भरने के निर्देश दिए गए हैं:)

अभ्यासः १: कोष्ठकम् पूरयत (Complete the missing word forms)

(क) ‘बाल’ शब्दरूपम् (like देव / राम) :
प्रथमा: बालः / बालौ / बालाः
द्वितीया: बालम् / बालौ / बालान्

(अर्थ: (क) 'बाल' शब्दरूप (देव/राम के समान) — प्रथमा: बालः (एक.) / बालौ (द्वि.) / बालाः (बहु.); द्वितीया: बालम् (एक.) / बालौ (द्वि.) / बालान् (बहु.)।)

प्रथमा: मुनिः / मुनी / मुनयः
तृतीया: मुनिना / मुनिभ्याम् / मुनिभिः

(अर्थ: (ख) 'मुनि' शब्दरूप (कवि/हरि के समान) — प्रथमा: मुनिः (एक.) / मुनी (द्वि.) / मुनयः (बहु.); तृतीया: मुनिना (एक.) / मुनिभ्याम् (द्वि.) / मुनिभिः (बहु.)।)

(ग) ‘लता’ शब्दरूपम् (like माला) :
प्रथमा: लता / लते / लताः
षष्ठी: लतायाः / लतयोः / लतानाम्

(अर्थ: (ग) 'लता' शब्दरूप (माला के समान) — प्रथमा: लता (एक.) / लते (द्वि.) / लताः (बहु.); षष्ठी: लतायाः (एक.) / लतयोः (द्वि.) / लतानाम् (बहु.)।)

अभ्यासः २: कोष्ठकात् उचितं रूपं चित्वा रिक्तस्थानानि पूरयत (Fill in the blanks)

(१) _______ पुस्तकं पठति। (अहम् / मम)
उत्तरम्: अहम् (I read the book) — अहम् पुस्तकं पठति।

(अर्थ: (1) रिक्तस्थान: अहम् पुस्तकं पठति। (विकल्प: अहम् / मम, उत्तर: अहम्)।)

(२) इदम् _______ गृहम् अस्ति। (मम / मया)
उत्तरम्: मम (This is my house) — इदम् मम गृहम् अस्ति।

(अर्थ: (2) रिक्तस्थान: इदम् मम गृहम् अस्ति। (विकल्प: मम / मया, उत्तर: मम — यह मेरा घर है)।)

(अर्थ: (3) रिक्तस्थान: शिक्षकः छात्राय ज्ञानं यच्छति। (विकल्प: छात्राय / छात्रेण, उत्तर: छात्राय — शिक्षक छात्र के लिए/को ज्ञान देता है)।)

(अर्थ: (4) रिक्तस्थान: वृक्षात् फलानि पतन्ति। (विकल्प: फलम् / फलानि, उत्तर: फलानि — वृक्ष से फल गिरते हैं)।)
