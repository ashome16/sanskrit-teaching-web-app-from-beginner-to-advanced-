Chapter 15 : परिशिष्टम् २ — धातुरूपाणि (Verb Conjugations)

(अध्याय १५ : परिशिष्ट २ — धातुरूपाणि तथा सन्धि-परिचयः / Verb Conjugations & Sandhi)

१. पूर्णः पाठः : लकाराः धातुरूपाणि च (Full Text - Verb Conjugations & Moods)

लकाराः (क्रियापदानां रूपाणि): सामान्यतः संस्कृतभाषायां २००० धातवः सन्ति।

(अर्थ: लकार (क्रियापदों के रूप): सामान्यतः संस्कृत भाषा में लगभग २००० धातुएँ हैं।)

तेभ्यः ‘तिङ्’ प्रत्ययान् योजयामः चेत् ते एव तिङन्ताः भवन्ति। तिङ्-प्रत्ययाः येषाम् अन्ते सन्ति ते तिङन्ताः। अथवा लकाराः इति वक्तुं शक्नुमः।

(अर्थ: उन धातुओं के साथ जब 'तिङ्' प्रत्यय जोड़ते हैं, तब वे 'तिङन्त' (क्रियापद) बनते हैं। जिनके अंत में तिङ् प्रत्यय होते हैं, उन्हें तिङन्त कहते हैं, अथवा इन्हें हम 'लकार' कह सकते हैं।)

धातवः त्रिप्रकारकाः भवन्ति – (१) परस्मैपदि-धातवः (२) आत्मनेपदि-धातवः (३) उभयपदि-धातवः।

(अर्थ: धातुएँ तीन प्रकार की होती हैं— 1. परस्मैपदी धातुएँ, 2. आत्मनेपदी धातुएँ, और 3. उभयपदी धातुएँ।)

I. लट्-लकारः (वर्तमानकालः - Present Tense)

१. परस्मैपदि-धातूनां लट्-लकारस्य रूपाणि — ‘पठ्’ धातुः (पढ़ना / To Read):

प्रथमपुरुषः (Third Person): पठति (एकवचनम्) पठतः (द्विवचनम्) पठन्ति (बहुवचनम्)
उदाहरण-प्रयोगः: बालः पठति / बालौ पठतः / बालाः पठन्ति।

(अर्थ: प्रथम पुरुष — पठति (एक पढ़ता है), पठतः (दो पढ़ते हैं), पठन्ति (सब पढ़ते हैं)। प्रयोग: बालक पढ़ता है / दो बालक पढ़ते हैं / सब बालक पढ़ते हैं।)

मध्यमपुरुषः (Second Person): पठसि (एकवचनम्) पठथः (द्विवचनम्) पठथ (बहुवचनम्)
उदाहरण-प्रयोगः: त्वं पठसि / युवां पठथः / यूयं पठथ।

(अर्थ: मध्यम पुरुष — पठसि (तू पढ़ता है), पठथः (तुम दोनों पढ़ते हो), पठथ (तुम सब पढ़ते हो)। प्रयोग: तू पढ़ता है / तुम दोनों पढ़ते हो / तुम सब पढ़ते हो।)

उत्तमपुरुषः (First Person): पठामि (एकवचनम्) पठावः (द्विवचनम्) पठामः (बहुवचनम्)
उदाहरण-प्रयोगः: अहं पठामि / आवां पठावः / वयं पठामः।

(अर्थ: उत्तम पुरुष — पठामि (मैं पढ़ता हूँ), पठावः (हम दोनों पढ़ते हैं), पठामः (हम सब पढ़ते हैं)। प्रयोग: मैं पढ़ता हूँ / हम दोनों पढ़ते हैं / हम सब पढ़ते हैं।)

एवम् (Similarly): लिख् (लिखति), खाद् (खादति), वद् (वदति), मिल् (मिलति), हस् (हसति), चल् (चलति), त्यज् (त्यजति), स्मृ-स्मर (स्मरति), पा-पिब (पिबति), क्रीड् (क्रीडति), नी-नय (नयति), प्रच्छ्-पृच्छ (पृच्छति), भू-भव (भवति), दृश्-पश्य (पश्यति), गम्-गच्छ (गच्छति) इत्यादयः।

(अर्थ: इसी प्रकार लिख्, खाद्, वद्, मिल्, हस्, चल्, त्यज्, स्मृ, पा, क्रीड्, नी, प्रच्छ्, भू, दृश्, गम् आदि परस्मैपदी धातुओं के रूप चलते हैं।)

२. विशेष-धातवः (Special Verbs in Present Tense - लट्-लकारः):

‘अस्’ धातुः (होना / To Be):
प्रथमपुरुषः: अस्ति (एक.) / स्तः (द्वि.) / सन्ति (बहु.)
मध्यमपुरुषः: असि (एक.) / स्थः (द्वि.) / स्थ (बहु.)
उत्तमपुरुषः: अस्मि (एक.) / स्वः (द्वि.) / स्मः (बहु.)

(अर्थ: 'अस्' धातु (होना) लट् लकार — प्रथम पुरुष: अस्ति, स्तः, सन्ति (है, दो हैं, सब हैं); मध्यम पुरुष: असि, स्थः, स्थ (तू है, तुम दो हो, तुम सब हो); उत्तम पुरुष: अस्मि, स्वः, स्मः (मैं हूँ, हम दो हैं, हम सब हैं)।)

‘कृ’ धातुः (करना / To Do):
प्रथमपुरुषः: करोति (एक.) / कुरुतः (द्वि.) / कुर्वन्ति (बहु.)
मध्यमपुरुषः: करोषि (एक.) / कुरुथः (द्वि.) / कुरुथ (बहु.)
उत्तमपुरुषः: करोमि (एक.) / कुर्वः (द्वि.) / कुर्मः (बहु.)

(अर्थ: 'कृ' धातु (करना) लट् लकार — प्रथम पुरुष: करोति, कुरुतः, कुर्वन्ति; मध्यम पुरुष: करोषि, कुरुथः, कुरुथ; उत्तम पुरुष: करोमि, कुर्वः, कुर्मः।)

‘श्रु’ धातुः (सुनना / To Hear):
प्रथमपुरुषः: शृणोति (एक.) / शृणुतः (द्वि.) / शृण्वन्ति (बहु.)
मध्यमपुरुषः: शृणोषि (एक.) / शृणूथः (द्वि.) / शृणुथ (बहु.)
उत्तमपुरुषः: शृणोमि (एक.) / शृण्वः-शृणुवः (द्वि.) / शृण्मः-शृणुमः (बहु.)

(अर्थ: 'श्रु' धातु (सुनना) लट् लकार — प्रथम पुरुष: शृणोति, शृणुतः, शृण्वन्ति; मध्यम पुरुष: शृणोषि, शृणूथः, शृणुथ; उत्तम पुरुष: शृणोमि, शृण्वः/शृणुवः, शृण्मः/शृणुमः।)

‘दा’ धातुः (देना / To Give):
प्रथमपुरुषः: ददाति (एक.) / दत्तः (द्वि.) / ददति (बहु.)
मध्यमपुरुषः: ददासि (एक.) / दत्थः (द्वि.) / दत्थ (बहु.)
उत्तमपुरुषः: ददामि (एक.) / दद्वः (द्वि.) / दद्मः (बहु.)

(अर्थ: 'दा' धातु (देना) लट् लकार — प्रथम पुरुष: ददाति, दत्तः, ददति; मध्यम पुरुष: ददासि, दत्थः, दत्थ; उत्तम पुरुष: ददामि, दद्वः, दद्मः।)

‘ज्ञा’ धातुः (जानना / To Know):
प्रथमपुरुषः: जानाति (एक.) / जानीतः (द्वि.) / जानन्ति (बहु.)
मध्यमपुरुषः: जानासि (एक.) / जानीथः (द्वि.) / जानीथ (बहु.)
उत्तमपुरुषः: जानामि (एक.) / जानीवः (द्वि.) / जानीमः (बहु.)

(अर्थ: 'ज्ञा' धातु (जानना) लट् लकार — प्रथम पुरुष: जानाति, जानीतः, जानन्ति; मध्यम पुरुष: जानासि, जानीथः, जानीथ; उत्तम पुरुष: जानामि, जानीवः, जानीमः।)

‘क्री’ धातुः (खरीदना / To Buy):
प्रथमपुरुषः: क्रीणाति (एक.) / क्रीणीतः (द्वि.) / क्रीणन्ति (बहु.)
मध्यमपुरुषः: क्रीणासि (एक.) / क्रीणीथः (द्वि.) / क्रीणीथ (बहु.)
उत्तमपुरुषः: क्रीणामि (एक.) / क्रीणीवः (द्वि.) / क्रीणीमः (बहु.)

(अर्थ: 'क्री' धातु (खरीदना) लट् लकार — प्रथम पुरुष: क्रीणाति, क्रीणीतः, क्रीणन्ति; मध्यम पुरुष: क्रीणासि, क्रीणीथः, क्रीणीथ; उत्तम पुरुष: क्रीणामि, क्रीणीवः, क्रीणीमः।)

३. आत्मनेपदि-धातूनां लट्-लकारस्य रूपाणि — ‘भाष’ धातुः (बोलना / To Speak):

प्रथमपुरुषः (Third Person): भाषते (एकवचनम्) भाषेते (द्विवचनम्) भाषन्ते (बहुवचनम्)
उदाहरण-प्रयोगः: सः भाषते / तौ भाषेते / ते भाषन्ते।

(अर्थ: प्रथम पुरुष — भाषते (वह बोलता है), भाषेते (वे दोनों बोलते हैं), भाषन्ते (वे सब बोलते हैं)। प्रयोग: सः भाषते / तौ भाषेते / ते भाषन्ते।)

मध्यमपुरुषः (Second Person): भाषसे (एकवचनम्) भाषेथे (द्विवचनम्) भाषध्वे (बहुवचनम्)
उदाहरण-प्रयोगः: त्वं भाषसे / युवां भाषेथे / यूयं भाषध्वे।

(अर्थ: मध्यम पुरुष — भाषसे (तू बोलता है), भाषेथे (तुम दोनों बोलते हो), भाषध्वे (तुम सब बोलते हो)। प्रयोग: त्वं भाषसे / युवां भाषेथे / यूयं भाषध्वे।)

उत्तमपुरुषः (First Person): भाषे (एकवचनम्) भाषावहे (द्विवचनम्) भाषामहे (बहुवचनम्)
उदाहरण-प्रयोगः: अहं भाषे / आवां भाषावहे / वयं भाषामहे।

(अर्थ: उत्तम पुरुष — भाषे (मैं बोलता हूँ), भाषावहे (हम दोनों बोलते हैं), भाषामहे (हम सब बोलते हैं)। प्रयोग: अहं भाषे / आवां भाषावहे / वयं भाषामहे।)

एवम् (Similarly): स्पर्ध्, यत्, वृध् (वर्ध), कूर्द्, कम्प्, राज् इत्यादयः।

(अर्थ: इसी प्रकार स्पर्ध् (प्रतियोगिता करना), यत् (प्रयत्न करना), वृध् (बढ़ना), कूर्द् (कूदना), कम्प् (काँपना), राज् (शोभित होना) आदि आत्मनेपदी धातुओं के रूप चलते हैं।)

II. लृट्-लकारः (भविष्यत्कालः - Future Tense)

१. परस्मैपदि-धातूनां लृट्-लकारः:

‘पठ्’ धातुः (पढ़ना / To Read):
प्रथमपुरुषः: पठिष्यति (एक.) / पठिष्यतः (द्वि.) / पठिष्यन्ति (बहु.)
मध्यमपुरुषः: पठिष्यसि (एक.) / पठिष्यथः (द्वि.) / पठिष्यथ (बहु.)
उत्तमपुरुषः: पठिष्यामि (एक.) / पठिष्यावः (द्वि.) / पठिष्यामः (बहु.)

(अर्थ: 'पठ्' धातु लृट् लकार (भविष्यत्काल) — पढ़ेगा, पढ़ेंगे; पढ़ेगा, पढ़ोगे; पढूँगा, पढ़ेंगे।)

‘लिख्’ धातुः (लिखना / To Write):
प्रथमपुरुषः: लेखिष्यति (एक.) / लेखिष्यतः (द्वि.) / लेखिष्यन्ति (बहु.)
मध्यमपुरुषः: लेखिष्यसि (एक.) / लेखिष्यथः (द्वि.) / लेखिष्यथ (बहु.)
उत्तमपुरुषः: लेखिष्यामि (एक.) / लेखिष्यावः (द्वि.) / लेखिष्यामः (बहु.)

(अर्थ: 'लिख्' धातु लृट् लकार (भविष्यत्काल) — लिखेगा, लिखेंगे; लिखेगा, लिखोगे; लिखूँगा, लिखेंगे।)

विशेष-परिवर्तनम्: ‘अस्’ धातुः भविष्यति (भू-आदेशः), ‘कृ’ धातुः करिष्यति, ‘श्रु’ → श्रोष्यति, ‘दा’ → दास्यति, ‘ज्ञा’ → ज्ञास्यति।

(अर्थ: लृट् लकार में कुछ धातुओं के विशेष रूप: अस् धातु का 'भविष्यति' (भू-आदेश), कृ का 'करिष्यति', श्रु का 'श्रोष्यति', दा का 'दास्यति', तथा ज्ञा का 'ज्ञास्यति' होता है।)

२. आत्मनेपदि-धातूनां लृट्-लकारः:

‘भाष’ धातुः (बोलना / To Speak):
प्रथमपुरुषः: भाषिष्यते (एक.) / भाषिष्येते (द्वि.) / भाषिष्यन्ते (बहु.)
मध्यमपुरुषः: भाषिष्यसे (एक.) / भाषिष्येथे (द्वि.) / भाषिष्यध्वे (बहु.)
उत्तमपुरुषः: भाषिष्ये (एक.) / भाषिष्यावहे (द्वि.) / भाषिष्यामहे (बहु.)

(अर्थ: 'भाष' धातु लृट् लकार (आत्मनेपद) — बोलेगा, बोलेंगे; बोलेगा, बोलोगे; बोलूँगा, बोलेंगे।)

III. लङ्-लकारः (भूतकालः - Past Tense)

१. परस्मैपदि-धातूनां लङ्-लकारः:

‘पठ्’ धातुः (पढ़ना / To Read):
प्रथमपुरुषः: अपठत् (एक.) / अपठताम् (द्वि.) / अपठन् (बहु.)
मध्यमपुरुषः: अपठः (एक.) / अपठतम् (द्वि.) / अपठत (बहु.)
उत्तमपुरुषः: अपठम् (एक.) / अपठाव (द्वि.) / अपठाम (बहु.)

(अर्थ: 'पठ्' धातु लङ् लकार (भूतकाल) — पढ़ा/पढ़ते थे; तूने पढ़ा/तुम दोनों ने पढ़ा/तुम सबने पढ़ा; मैंने पढ़ा/हम दोनों ने पढ़ा/हम सबने पढ़ा।)

‘अस्’ धातुः (होना / To Be):
प्रथमपुरुषः: आसीत् (एक.) / आस्ताम् (द्वि.) / आसन् (बहु.)
मध्यमपुरुषः: आसीः (एक.) / आस्तम् (द्वि.) / आस्त (बहु.)
उत्तमपुरुषः: आसम् (एक.) / आस्व (द्वि.) / आस्म (बहु.)

(अर्थ: 'अस्' धातु लङ् लकार (भूतकाल) — था, थे; तू था, तुम दो थे, तुम सब थे; मैं था, हम दो थे, हम सब थे।)

‘कृ’ धातुः (करना / To Do):
प्रथमपुरुषः: अकरोत् (एक.) / अकुरुताम् (द्वि.) / अकुर्वन् (बहु.)
मध्यमपुरुषः: अकरोः (एक.) / अकुरुतम् (द्वि.) / अकुरुत (बहु.)
उत्तमपुरुषः: अकरवम् (एक.) / अकुर्व (द्वि.) / अकुर्म (बहु.)

(अर्थ: 'कृ' धातु लङ् लकार (भूतकाल) — किया/करते थे; तूने किया/तुम दोनों ने किया/तुम सबने किया; मैंने किया/हम दोनों ने किया/हम सबने किया।)

IV. लोट्-लकारः (आज्ञार्थे - Imperative Mood)

‘पठ्’ धातुः (पढ़ना / To Read):
प्रथमपुरुषः: पठतु (एक.) / पठताम् (द्वि.) / पठन्तु (बहु.)
मध्यमपुरुषः: पठ (एक.) / पठतम् (द्वि.) / पठत (बहु.)
उत्तमपुरुषः: पठानि (एक.) / पठाव (द्वि.) / पठाम (बहु.)

(अर्थ: 'पठ्' धातु लोट् लकार (आज्ञा/प्रार्थना) — वह पढ़े, वे दो पढ़ें, वे सब पढ़ें; तू पढ़, तुम दोनों पढ़ो, तुम सब पढ़ो; मैं पढूँ, हम दो पढ़ें, हम सब पढ़ें।)

‘अस्’ धातुः (होना / To Be):
प्रथमपुरुषः: अस्तु (एक.) / स्ताम् (द्वि.) / सन्तु (बहु.)
मध्यमपुरुषः: एधि (एक.) / स्तम् (द्वि.) / स्त (बहु.)
उत्तमपुरुषः: असानि (एक.) / असाव (द्वि.) / असाम (बहु.)

(अर्थ: 'अस्' धातु लोट् लकार — अस्तु (हो/कल्याण हो), स्ताम्, सन्तु; एधि (तू हो), स्तम्, स्त; असानि (मैं होऊँ), असाव, असाम।)

V. विधिलिङ्-लकारः (प्रार्थना/चाहिए - Potential Mood)

‘पठ्’ धातुः (पढ़ना / To Read):
प्रथमपुरुषः: पठेत् (एक.) / पठेताम् (द्वि.) / पठेयुः (बहु.)
मध्यमपुरुषः: पठेः (एक.) / पठेतम् (द्वि.) / पठेत (बहु.)
उत्तमपुरुषः: पठेयम् (एक.) / पठेव (द्वि.) / पठेम (बहु.)

(अर्थ: 'पठ्' धातु विधिलिङ् लकार (चाहिए अर्थ में) — उसे पढ़ना चाहिए, उन दोनों को पढ़ना चाहिए, उन सबको पढ़ना चाहिए; तुम्हें पढ़ना चाहिए; मुझे पढ़ना चाहिए।)

‘अस्’ धातुः (होना / To Be):
प्रथमपुरुषः: स्यात् (एक.) / स्याताम् (द्वि.) / स्युः (बहु.)
मध्यमपुरुषः: स्याः (एक.) / स्यातम् (द्वि.) / स्यात (बहु.)
उत्तमपुरुषः: स्याम् (एक.) / स्याव (द्वि.) / स्याम (बहु.)

(अर्थ: 'अस्' धातु विधिलिङ् लकार — स्यात् (होना चाहिए/हो), स्याताम्, स्युः; स्याः, स्यातम्, स्यात; स्याम्, स्याव, स्याम।)

VI. अधिकं जानीमः: सन्धीनां सामान्यः परिचयः (Introduction to Sandhi)

उच्चारणसमये परस्परं वर्णानाम् अत्यन्तं सामीप्यं ‘संहिता’ भवति। यदा संहिता भवति तदा वर्णेषु परिवर्तनं भवति।

(अर्थ: बोलते समय वर्णों की अत्यधिक निकटता को 'संहिता' कहते हैं। जब संहिता होती है तब वर्णों में विकार (परिवर्तन) आता है।)

एवं प्रकारेण यत्र संहिताद्वारा वर्णानां परिवर्तनं भवति तस्यैव ‘सन्धिः’ इति नाम।

(अर्थ: इस प्रकार जहाँ संहिता के द्वारा वर्णों में परिवर्तन होता है, उसी का नाम 'सन्धि' है।)

व्याकरणे प्रमुखतया त्रयः सन्धयः सन्ति: (१) स्वरसन्धिः (२) व्यञ्जनसन्धिः (३) विसर्गसन्धिः।

(अर्थ: संस्कृत व्याकरण में मुख्य रूप से तीन संधियाँ होती हैं— 1. स्वरसंधि (अच्-संधि), 2. व्यंजनसंधि (हल्-संधि), और 3. विसर्गसंधि।)

स्वरसन्धयः (अच्-सन्धयः) – सप्त प्रकाराः :

१. सवर्णदीर्घसन्धिः : अ/आ, इ/ई, उ/ऊ, ऋ के बाद समान वर्ण आने पर दीर्घ (आ, ई, ऊ, ॠ) हो जाता है।
तत्रापि = तत्र + अपि (अ + अ = आ)
रवीन्द्रः = रवि + इन्द्रः (इ + इ = ई)
गुरूत्सवः = गुरु + उत्सवः (उ + उ = ऊ)

(अर्थ: सवर्णदीर्घ सन्धि: ह्रस्व या दीर्घ अ, इ, उ, ऋ के बाद समान स्वर आए तो दोनों मिलकर दीर्घ हो जाते हैं, जैसे— तत्रापि = तत्र + अपि; रवीन्द्रः = रवि + इन्द्रः; गुरूत्सवः = गुरु + उत्सवः।)

२. गुणसन्धिः : अ/आ के बाद इ/ई आए तो 'ए', उ/ऊ आए तो 'ओ', और ऋ आए तो 'अर्' हो जाता है।
सुरेन्द्रः = सुर + इन्द्रः (अ + इ = ए)
महोत्सवः = महा + उत्सवः (आ + उ = ओ)
महर्षिः = महा + ऋषिः (आ + ऋ = अर्)

(अर्थ: गुण सन्धि: अ/आ के बाद इ/ई आए तो 'ए', उ/ऊ आए तो 'ओ', तथा ऋ आए तो 'अर्' बनता है, जैसे— सुरेन्द्रः, महोत्सवः, महर्षिः।)

३. वृद्धिसन्धिः : अ/आ के बाद ए/ऐ आए तो 'ऐ', ओ/औ आए तो 'औ' हो जाता है।
एकैकम् = एक + एकम् (अ + ए = ऐ)
तथैव = तथा + एव (आ + ए = ऐ)
परमौषधिः = परम + ओषधिः (अ + ओ = औ)

(अर्थ: वृद्धि सन्धि: अ/आ के बाद ए/ऐ आने पर 'ऐ' तथा ओ/औ आने पर 'औ' वृद्धि एकादेश होता है, जैसे— एकैकम्, तथैव, परमौषधिः।)

४. यण्-सन्धिः : इ/ई, उ/ऊ, ऋ, ऌ के बाद असमान स्वर आने पर क्रमशः य्, व्, र्, ल् हो जाता है।
इत्यपि = इति + अपि (इ + अ = य)
स्वागतम् = सु + आगतम् (उ + आ = वा)

(अर्थ: यण् सन्धि: इ/ई के स्थान पर य्, उ/ऊ के स्थान पर व्, ऋ के स्थान पर र्, तथा ऌ के स्थान पर ल् हो जाता है जब बाद में कोई असमान स्वर हो, जैसे— इत्यपि = इति + अपि; स्वागतम् = सु + आगतम्।)

२. शब्दार्थ-विवरणम् (Word-to-Word Meaning & Grammatical Notes)

धातवः: धातु (मूल क्रिया रूप) — क्रिया के मूल रूप (Root verbs)
तिङन्ताः: तिङ् + अन्तः (प्रत्यय) — क्रियापद / तिङ् प्रत्यय वाले (Conjugated verb forms)
लट्-लकारः: वर्तमानकालः — वर्तमान काल (Present Tense)
लृट्-लकारः: भविष्यत्कालः — भविष्य काल (Future Tense)
लङ्-लकारः: भूतकालः — भूत काल (Past Tense)
लोट्-लकारः: आज्ञार्थक रूप — आज्ञा / प्रार्थना काल (Imperative Mood)
विधिलिङ्: चाहिए / सम्भावना — चाहिए के अर्थ में (Potential Mood)
संहिता: वर्णानां सामीप्यम् — वर्णों की अत्यधिक निकटता (Extreme phonetic proximity)
असवर्णाः स्वराः: असमान स्वरः — भिन्न स्वर (Dissimilar vowels)
भवति: भू धातु (लट्, प्र.पु, एक.) — होता है / होती है (Happens / Becomes)
शक्नुमः: शक् धातु (लट्, उत्.पु, बहु.) — हम सब समर्थ हैं (We are able to)
योजयामः: युज् धातु + णिच् — हम सब जोड़ते हैं (We join / add)

(अर्थ: प्रमुख व्याकरणिक पदों के शब्दार्थ: धातवः (मूल क्रिया), तिङन्ताः (क्रियापद), लट् (वर्तमान), लृट् (भविष्यत्), लङ् (भूतकाल), लोट् (आज्ञा), विधिलिङ् (चाहिए), संहिता (वर्णों की अतिनिकटता), भवति (होता है), शक्नुमः (हम समर्थ हैं), योजयामः (हम जोड़ते हैं)।)
